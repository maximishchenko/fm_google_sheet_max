В google таблице есть данные по поставленным задачам из менеджеру - https://docs.google.com/spreadsheets/d/1my8x2_ZSujjeJJ7Ub-JMEWdCkvYk6KfGdnGACRzKtP4/edit?gid=729018895#gid=729018895
Нужно написать приложение на python, которое будет получать задачи менеджера и отправлять через бота max менеджеру
В дальнейшем будет несколько таблиц, каждая содержит задачи одного менеджера и должна быть отправлена этому менеджеру
Список таблиц и получателей задаётся в файле config.json: токен бота (max_bot_token) и массив tables, где у каждой таблицы указаны url и список chat_ids для отправки. Пример см. в docstring main.py. Запуск: python main.py

Скрипт рассчитан на запуск по расписанию: уже отправленные задачи хранятся в sent_tasks.json и повторно не отправляются; список сбрасывается каждый день. Если новых задач на сегодня нет — сообщение не отправляется.
